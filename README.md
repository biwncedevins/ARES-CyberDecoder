# CyberDecoder

أداة سطح مكتب تعمل **بدون إنترنت** لفك الترميز متعدد الطبقات وتحليل النتيجة: تكتشف نوع الترميز تلقائيًا، تفكّه طبقة بعد طبقة، ثم تستخرج المؤشرات (IOCs) وتنبّه إلى الأنماط المشبوهة.

## التشغيل السريع

**Windows**: انقر مرتين على `run_windows.bat` (يثبّت PySide6 مرة واحدة ثم يفتح البرنامج).
**Linux / macOS**: `./run.sh`
يدويًا: `pip install -r requirements.txt` ثم `python main.py`

## بناء ملف EXE مستقل (Windows)

انقر مرتين على `build_windows.bat`. الناتج: `dist\CyberDecoder.exe` (ملف واحد يعمل دون تثبيت Python).
على Linux/macOS: `./build.sh`.

## الاستخدام

1. الصق النص أو اسحب ملفًا إلى النافذة (أو `Ctrl+O` لفتح ملف، `Ctrl+Shift+V` للصق).
2. اضغط **تحليل** (`Ctrl+Enter`) أو فعّل «تحليل تلقائي».
3. راجع اللافتة العلوية (سلسلة الفك)، ثم التبويبات: الناتج النهائي، الطبقات، المؤشرات، مقاطع مضمّنة، ملاحظات، التقرير.
4. انسخ الناتج، أو صدّر تقرير TXT / JSON، أو احفظ الناتج الخام.

جرّب ملفات المجلد `samples/` أو زر «تحميل مثال».

## ما الذي يفكّه

Base64 (عادي/URL-safe/بدون padding/أسطر ملفوفة) · Base32 · Hex (`\x41` و`0x41` وأزواج مفصولة) · URL Encoding · Unicode escapes (`\uXXXX`, `%uXXXX`) · HTML entities · Gzip · Zlib · JWT · JSON · PowerShell `-EncodedCommand` (UTF-16LE).
يكتشف أيضًا مقاطع مشفّرة **داخل** نص أكبر (مثل سجل أو قيمة JSON) ويفكّها منفصلة.

## المؤشرات المستخرجة

URLs · Domains · IPv4 · Emails · مسارات Windows (وUNC) · مفاتيح Registry · Hashes (MD5/SHA1/SHA256). تعيد الصيغ المعطّلة مثل `hxxp` و`[.]` إلى أصلها قبل الاستخراج.

## الحماية

- حد أقصى لعمق الفك (افتراضيًا 12).
- كشف الحلقات (ناتج يتكرر) وإيقاف الفك.
- سقف 32MB للناتج المضغوط (حماية من Zip bomb).
- لا اتصال بالشبكة إطلاقًا، ولا يُنفَّذ أي شيء مما يُفكّ. كل المحتوى يُعامل كبيانات فقط.
- يُنصح بفتح العينات الخطرة على جهاز معزول.

## بنية المشروع

```
main.py                 نقطة التشغيل
cyberdecoder/engine.py  المحرك: الكشف والفك والتحقق
cyberdecoder/ioc.py     استخراج المؤشرات
cyberdecoder/interpret.py  قواعد التفسير والملاحظات
cyberdecoder/report.py  تقارير TXT / JSON
cyberdecoder/gui.py     الواجهة (PySide6)
cyberdecoder/theme.py   الألوان والتنسيق
tools/make_icon.py      مولّد الأيقونة
tests/                  الاختبارات:  python -m unittest discover -s tests -t .
```

## حدود معروفة

- الكشف قائم على الإحصاء والتحقق، لذا قد تمرّ نصوص عشوائية تشبه Base64 بندرة (حوالي 0.07% في اختباراتنا)؛ راجع تبويب «الطبقات» للتأكد من الثقة.
- التشفير الحقيقي (AES وRC4 وXOR) غير مدعوم؛ الأداة لفك الترميز لا كسر التشفير.
- الملفات الأكبر من 5MB لا تُحمَّل من الواجهة.
